# Sobre esta página

## ¿Qué puede responder este asistente?
Este asistente responde preguntas generales sobre la Oficina del Agua: tarifas vigentes, cómo se calcula el consumo, formas de pago, trámites, horarios y qué hacer ante una fuga. Sus respuestas se basan únicamente en la información oficial cargada en el sistema.

## ¿Puede el asistente decirme mi saldo o mis pagos?
No. Por seguridad, el asistente no tiene acceso a datos de ninguna cuenta ni a información personal. Para ver el estado de tu cuenta usa la sección "Consulta pública" e ingresa el código de tu contador.

## ¿Qué es la consulta pública?
Es una sección de esta página donde cualquier persona puede consultar el estado de cuenta de un contador sin crear un usuario. Solo necesitas el código del contador y resolver un captcha, que evita que programas automáticos consulten datos de forma masiva.

## ¿Dónde encuentro el código de mi contador?
El código de tu contador aparece impreso en tu recibo o boleta de pago. También está en una placa o etiqueta en el propio contador.
